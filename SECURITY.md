# Security

This is a development fork. Its tested local behavior does not establish production readiness, compatibility with every Codex version or deployment, or universal zero egress. See [current evidence](docs/VERIFICATION.md) and [data/security boundaries](docs/SECURITY.md).

## Report a concern privately

Use the private vulnerability-reporting channel configured by this repository's maintainer. If GitHub private vulnerability reporting is enabled, use the repository's **Security** tab. When no private channel is configured, arrange private contact before sharing exploit details publicly.

Include the affected source revision/version, a concise impact description, a minimal synthetic reproduction and any relevant sanitized evidence. Do not send credentials, launch tokens, private configuration, private repositories or transcripts. Do not test against other users, third-party systems or real model accounts without authorization.

There is no promised response time or security support SLA. Fixes and advisories must describe the verified scope and remaining limitations. Deployment controls and the approved CLI's policy remain separate from application code.
